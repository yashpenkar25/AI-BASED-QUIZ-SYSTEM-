# 🤖 AI-Based Quiz System

An AI-powered web application that automates quiz creation, management, and evaluation using **Google Gemini AI**. The platform enables educators to generate quizzes from PDF documents while providing students with an interactive assessment experience featuring secure authentication, leaderboards, and instant results.

---

## 🚀 Features

- 🔐 Secure Login & Registration
- 👨‍💼 Admin Dashboard
- 👨‍🏫 Paper Setter Portal
- 👨‍🎓 Candidate Portal
- 📄 AI-Based MCQ Generation from PDF
- 🤖 Google Gemini AI Integration
- 📝 Manual Question Management
- 📅 Quiz Scheduling
- 📊 Real-time Result Evaluation
- 🏆 Leaderboard
- 👤 User Profile Management
- 📱 Responsive Web Interface

---

## 🤖 AI Quiz Generation

The Paper Setter can upload a PDF document.

The system:

- Extracts text using **PyPDF2**
- Sends the content to **Google Gemini AI**
- Automatically generates Multiple Choice Questions (MCQs)
- Saves generated questions for future quizzes
